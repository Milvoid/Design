## 过程

1. 初版是深墨蓝底、青绿强调、黑体标题的“发布会”风格，被用户评价为“简单 slides 页面的放映，没有审美”。问题：像监控后台、构图单一、动效只有计数和淡入、界面截图占主体且字小、配乐不合气质。
2. 改用 Anthropic 式的人文、编辑风格（只借风格语言，不用其名称、标志、插画和授权字体），定出暖白纸面 + 墨色 + 陶土的方案，写成 v2 美术方向。
3. 字体：思源宋体 / 黑体被用户否决；调研 8 款中文衬线、3 款正文、3 款西文数字后，用户选定寒蝉锦书宋 Pro + Source Serif 4 + 霞鹜新晰黑。
4. 用户提供 Painting Loaders 作为笔触参考，用来打破“平底 + 文字 + 配图”的单调感，要求只平衡视觉和衔接、不喧宾夺主；落地为加载、转场、片尾三种用法。
5. 五轮审阅（样张 → 字体 → 笔触 → 01 小样 → 成片），常见问题已汇总进 review.md。
