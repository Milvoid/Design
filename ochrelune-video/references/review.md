# 导演审阅

执行者交审阅图，导演（中台或用户）看图后按镜号提意见，明确说“通过”才进下一阶段。执行者不自行宣布完成。

## 各阶段交什么

| 阶段 | 交付 | 导演看什么 |
|---|---|---|
| 1 分镜与样张 | 分镜表；每片 6 张 1920×1080 关键帧 + 一张总览；浅色原型关键页 2x 截图；配乐文件 | 叙事是否通顺、构图是否轮换、插画是否够简、字号、配色焦点 |
| 2 字体与修订样张 | 换好正式字体的同组样张，旁边附上一轮原图对照；字形核验记录 | 字体在画面里的气质、缺字 |
| 3 笔触测试（一支片） | 加载、转场、收尾三段，各一张每 0.25 秒一帧的条带 + 末帧原图；全片笔触时间分布表 | 是否抢文字、颜色是否在色板内、用量 |
| 4 动画小样（一支片） | 720p 带乐 mp4；每 1 秒一帧的逐秒总览（每张 ≤ 20 帧，标注时间和镜号）；镜头实际起止时间 | 节奏、空白、跳位、停读时间、结尾 |
| 5 成片 | 1080p mp4；改动镜头的逐秒总览 | 上一轮问题是否都改到 |

逐秒总览从**编码后的 mp4** 抽帧（`ffmpeg -vf "select='not(mod(n,30))',scale=384:216"`），不要从源帧拼，确保看到的就是交付物。参考 [assets/overview.py](../assets/overview.py)。

## 提意见的方式

- 先说整体判断（方向对不对、哪些保留），再按“全局 / 镜号”逐条写问题和改法。
- 每条给出可执行的改法和数值，例如“纯文字镜头压到 2.5 秒”“关键句 1080p 下 ≥ 32 px”“透明度降到 45%”。
- 执行者自己拿不准的地方要在交付里点名，导演优先回应这些。

## 常见问题清单（交我创五轮审阅实际出现过的）

**画面**
- 插画像工程线稿：引脚、散热格、机架小字太多。→ 简化到一眼认出。
- 辅助色太饱和、面积太大，抢走陶土焦点（雾蓝最常见）。
- 说明小字低于 28 px。→ 删字也要放大。
- 界面特写里被聚焦的卡片本身发灰。→ 蒙层只压周围。
- 截图顶部露出半行被截断的字、空占位条。
- 实际用量线贴着基线看不见。→ 加粗换色，线端直标。
- 中文数字做钩子读不出落差。→ 阿拉伯数字 + 大号衬线数字。
- 矢量物件放进笔触底景里质感不搭、尺寸过大。→ 缩小、降饱和、加一点干刷纹理。

**动效与节奏**
- 开头 1 秒空白纸面。→ ≤ 0.3 秒。
- 纯文字镜头停 5 秒。→ ≤ 2.5 秒。
- 标题出场后中途跳位。
- 镜头之间出现一整秒空白。
- 元素退场不同步，单个物件留在空画面里。
- 界面关键句读不清、停留太短。→ 推近或重排，给足停读。
- 片尾刚画完就结束。→ 定格 2 秒 + 0.8 秒淡出，音乐末句同步延长。

**笔触**
- 转场笔触太厚、颜色太实，压住还没退场的标题。→ 薄、横向、浅色为主，文字先退场。
- 加载动画悬在空白处和画面无关。→ 放到下一镜要出现的界面附近。

## 替换交付物

成片先放审阅目录；导演通过后按原文件名替换提交目录，旧版移入归档目录（不删），核对哈希一致后再报告。
