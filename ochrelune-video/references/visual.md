# 画面

气质像一本排版讲究的杂志，或一部安静的纪录短片。温暖、克制、留白多，有手作感。不用科技感霓虹、发光、深色大屏、粒子、渐变。

## 色板

| 角色 | 色值 | 用法 |
|---|---|---|
| 纸面 | `#FAF9F5` | 默认底色 |
| 燕麦 | `#F0EEE6` | 次级底色、插画镜头底、聚焦时的蒙层 |
| 卡片 | `#E8E6DC` | 卡片和纸张 |
| 墨色 | `#141413` | 标题、线描 |
| 次级文字 | `#5E5D59` | 正文、说明 |
| 弱化 | `#87867F` | 署名、时间 |
| 陶土 | `#D97757` | 每镜唯一焦点：一格芯片、一道下划线、一笔批注 |
| 辅助色 | 橄榄 `#788C5D` / 卡其 `#D4A27F` / 雾蓝 `#6A9BCC` | 每支片选一个，只做衬底色块或一小块填充 |

- 全片不出现纯黑底。需要压暗时用燕麦蒙层，不用黑色。
- 辅助色饱和度过高或面积过大会抢走焦点（雾蓝最容易发闷，宁浅勿深）。

## 字体

| 角色 | 字体 | 字号（1080p） |
|---|---|---|
| title | 寒蝉锦书宋 Pro Medium | 镜头标题 64–88 px，≤ 12 字 |
| body | 霞鹜新晰黑 Regular（含正文里的西文和数字） | ≥ 28 px；说明一镜最多一行半 |
| number | Source Serif 4，wght 500 / opsz 48 | 大数字 ≥ 160 px，中文单位用小号 body |

- 一个镜头最多两种字号层级加一个大数字。
- 钩子里的数字用阿拉伯数字配大号衬线数字，中文数字不利于一眼读出落差。
- 字体授权：锦书宋、Source Serif 4 为 SIL OFL 1.1，新晰黑为 IPA Font License 1.0。渲染前按实际用字子集化（见 pipeline.md），换文案后重新检查缺字，尤其生僻字和全角标点。

## 五种构图

整片轮流使用，不允许一个构图用到底：

1. **满屏一句宋体大字**：章节标题，如“先把低效作业找出来”。居中或明确偏置，位置出场后固定。
2. **插画居中配一行字**：机柜、单据、书本等线描，下方一行宋体短句。
3. **左右分栏**：左边大数字或标题，右边插画；或反过来。
4. **界面特写**：浅色主题原型放在柔和投影的圆角窗口里，推近到一句话。
5. **线描数据图**：墨色细线画出折线或面积，关键差距用陶土或辅助色填充；去掉网格和图例，只直标关键值（“实际约 1 核”配细引线）。

四周至少留白 120 px。去掉顶部小标签、页脚、日期这类装饰信息，只留要读的字。

## 插画

- 单色线描，墨色线条，线宽略有变化；配一两块辅助色或陶土色的有机色块（不规则圆角，像剪纸）。
- **简化到一眼认出**：一个芯片、一台机柜、一叠单据、一本书。去掉引脚、散热格、小字、机架编号这类构造细节。
- 统一来源：插画是 SVG，视频、pitch book、文档封面复用同一份源文件。
- 隐喻优先：64 格只亮一格（申请多、用得少）；放大镜对着签名栏（找缺漏）；红圈圈住一个算错的均值（找错）；笔尖写下最后一个勾（人来确认）。

## 界面镜头

- 原型先换成和色板一致的浅色主题，只改样式（CSS 变量、颜色、字体、圆角、阴影），不改功能和数据。
- 用 Playwright 以 2x 设备像素比截图，同时记录关键元素的包围盒（见 pipeline.md 的“取景”）。
- 每个界面镜头：全貌约 1 秒 → 镜头推到要讲的那块，放大到字清楚 → 周围用燕麦蒙层压淡。**被聚焦的那块保持原对比度**，蒙层只压周围。
- 推近后关键句仍小于 32 px 时，在卡片下方用 body 字体把这句话重排一遍（交我创 01 镜 10 用 43 px 两行重排，停读 3.7 秒）。
- 不加设备外框，不出现被截断的半行字和空占位条。
