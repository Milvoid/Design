# 插画、截图、图表与图标

每一张图都要解释、佐证或隐喻当前这页的内容。去掉之后内容更清楚的图，就不该出现。

**能画成图的内容就画成图**，这是让课程 Pre 显得学术、专业，又不堆文字的主要办法（2026-11-19 Milvoid 的要求）。两栏文字块组成的 deck 会被认为是文字堆砌。常用的图：

| 内容 | 图 |
|---|---|
| 多方之间谁在什么时候付钱给谁 | 资金流向图、泳道时序图（单据用虚线，资金用实线） |
| 事件先后、账期、缺口 | 时间轴（标出关键日和间隔天数） |
| 余额从期初到期末的变化 | 瀑布图 |
| 不同方案或天数下的成本 | 柱状图（直接标数值，和基准利率画一条参考线） |
| 两种成本相等的临界点 | 两条线相交的盈亏分界图，交点高亮 |
| 决策步骤 | 决策树或流程图 |
| 机构之间的融资、担保、保险关系 | 结构关系图 |
| 双方各得多少 | 分解条 |
| 各方责任或做法对照 | 对照表或双路径对比图 |

页面上保留结论式标题、图和两三句必要说明，细节移进讲稿。

## 插画

- **按 ochrelune 插画设计语言现画**，规则见 [ochrelune-video/references/illustration.md](../../ochrelune-video/references/illustration.md)：几样日常物件（纸、卡片、夹板、放大镜、笔……）稍微歪着叠在一起讲一个动作；墨色外轮廓 3.8、灰色细节 2.0–2.4；前纸纸面色、后纸燕麦色；一张图只有一处陶土；最重要的物件下面垫一块浅色有机色块。不用现成的图标库或网上找的线性图标。
- 和配套视频是同一种画法，可以直接复用视频里已经画好的图，也可以照规则新画，放在一起要像一家人。
- 插画在一页里通常占 4–7 列；流程节点约 120 px；封面和结尾可以更大。
- 隐喻要和内容对得上：64 格芯片只亮一格 = 申请多用得少；放大镜压在格子卡片上 = 检查用量；陶土色的勾 = 人来确认。

## 截图

- 只截和讲解相关的区域，裁掉菜单、浏览器边框和无关面板；用 2x 分辨率截取。
- 放进圆角（16–20 px）和柔和阴影（`0 24px 48px -24px rgba(20,20,19,.25)`）的窗口里，不加设备外框。
- 要讲的位置用编号圆点或细框标出，标注文字放在截图旁边并对齐，编号与讲稿顺序一致。截图里的字读不清时，把关键句在旁边用正文字体重排一遍。
- 浅色主题的界面截图和纸面背景最协调；深色界面先换成浅色主题再截。

## 图表

- 用代码画（SVG 或图表库），配色来自 ochrelune-design 的数据色板；不截图别人的图表。
- **直接标注**：数值标在数据点或折线末端旁边，不用单独的图例。
- 去掉多余网格线、边框、3D 效果和渐变；只保留读懂这张图必需的坐标与刻度。
- 饼图超过 5 类改用条形图；比较长度优先于比较面积和角度。
- 图表里的文字不小于 36 px；系列除颜色外再用线型或标记区分。
- 关键差距用陶土或辅助色填充，并在旁边写一句结论。

## 图标

- 小标题旁、要点前的小图标（48–68 px）也按插画设计语言 §5 画：一个物件加一个细节，外轮廓 2.6–3.0，不加底色块，最多一个陶土小点。全篇所有图标出自同一种画法，不混用 SF Symbols、Material 或图标字体。
- 图标高度与相邻文字的字高相近，与文字中线对齐；并排时间距一致。
- 图标只配合文字，不替代文字；含义可能被猜错的图标就不用。

## 代码

- 等宽字体，字号不小于 36 px，语法高亮只用墨色、次级灰和一个强调色。
- 长代码拆成小段分步呈现，每段旁边一句话说明它在做什么。
