# 字体、颜色与强调

## 字体

沿用 ochrelune-design §5.1.1 的方案：

| 角色 | 字体 | 用在 |
|---|---|---|
| title | 寒蝉锦书宋 Pro Medium | 封面、章节、页标题 |
| body | 霞鹜新晰黑 Regular | 正文、要点、说明、图表文字、页脚 |
| number | Source Serif 4（500） | 大数字、页码 |
| mono | 系统等宽字体 | 代码 |

- 正文只用无衬线。衬线只用于 64 px 以上的标题和大数字：锦书宋笔画粗、竖画厚，在投影上比细宋体稳，但仍要在目标投影环境下确认。投影条件很差时，标题可以整套换成霞鹜新晰黑，不要半套换。
- 一套演示只用这三种字体，不出现艺术字、手写体正文。

## 字号（1920×1080 画布）

按“文字高度至少占屏幕高度 1/50”的原则，1 pt ≈ 2 px：

| 层级 | 默认 | 范围 | 底线 |
|---|---|---|---|
| 页标题 | 72 px | 64–88 px | 64 px |
| 副标题 | 40 px | 36–44 px | 32 px |
| 小主题（左侧竖条） | 48 px | 44–52 px | 40 px |
| 正文 / 要点 | 40 px（20 pt） | 36–48 px | 36 px（18 pt） |
| 注释 / 图例 / 出处 / 表格 | 32 px | 28–36 px | 28 px（14 pt） |
| 封面作品名 | 104 px | 96–120 px | — |
| 大数字 | 180 px | 140–220 px | — |

内容放不下时拆页或删字，不缩小字号到底线以下。

## 行距与段距

- 正文行高 1.5（范围 1.2–1.6），标题行高 1.2。
- 段后间距 0.5 行（范围 0.5–1 行），用 CSS `margin`，不用空行。中文段落首行缩进两字。
- 中文正文左对齐，不两端拉伸；不整段全大写，不压缩或拉大字距。

## 颜色

| 角色 | 色值 | 占比 |
|---|---|---|
| 纸面背景 | `#FAF9F5` | 约 60% |
| 墨色标题 `#141413`、正文 `#2E2D2A`、次级 `#5E5D59` | | 约 30% |
| 陶土强调 `#D97757`（文字用深陶土 `#9F5038`） | | 约 10%，只给结论、关键数字 |
| 辅助色（橄榄 `#788C5D` / 卡其 `#D4A27F` / 雾蓝 `#6A9BCC`，选一个） | | 插画色块、图表第二系列 |

- **投影**：投影会降低饱和度和亮度，燕麦色、浅卡其、浅雾蓝这类浅色在投影上几乎看不见，只能做背景色块，不承担信息。正文不用 `#87867F` 这种弱化灰，最浅用 `#5E5D59`。
- **对比度**：文字与背景至少 4.5:1；大字（≥ 48 px）至少 3:1。浅色陶土 `#D97757` 不直接做小字号文字，文字用 `#9F5038`。
- **区分信息不只靠颜色**：图表系列同时用线型、标记或直标区分；不用红绿并置。
- **全篇一致**：同一类信息始终用同一个颜色（例如“问题”始终陶土、“已解决”始终橄榄），不中途改。
- 背景只用纯色纸面，章节页可用燕麦色；不放图片背景、纹理和渐变。

## 强调

- 用**高亮文本**代替加粗：要强调的词改用深陶土色 `#9F5038`（`<em>`）。引导式要点的引导词、正文里的关键结论都用这一种；不加粗，保持字重一致。
- 需要更强的提示时（全页只一处），可以在关键数字下加一条陶土半透明底条（`<mark>`）。
- 一页只强调一处主焦点，最多再有一两处次要强调（用墨色、字号或位置区分）。
- 不用感叹号、阴影、发光、浮雕制造重点。
- 中文不做大段加粗；需要分层时用字号、颜色深浅和位置。
