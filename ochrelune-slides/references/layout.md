# 排版与信息量

画布固定 1920×1080（16:9），所有尺寸按这个画布的像素写。放映时整体等比缩放。

## Slides 不是视频

视频一镜一句，观众被时间轴带着走；slides 是讲者和观众共用的“讲义页”，观众会停下来读，讲者也要靠它展开讲解。所以一张内容页是一个**完整的论证单元**：一个结论（标题），加上支撑它的解释、依据和例子。只放关键词的页面，讲者讲完观众什么也留不下，下来翻 PDF 也看不懂。

判断标准：**不听讲解，单看这一页，能不能读懂它在说什么、为什么成立。**

## 网格与安全区

- **12 列网格**：左右边距 120 px，栏间距 32 px，每列约 108 px。
- **安全区**：上 88 px、下 80 px、左右 120 px 以内不放内容。
- **固定区域**：标题区从顶边 88 px 起（标题 + 副标题约占 170 px）；内容区约 y = 290 到 y = 980；页脚在 y = 1020 附近（左侧短题名，右侧页码），封面、章节页、结尾页不显示。
- 所有元素对齐到网格线或彼此的边缘，不存在“差一点对齐”。同组元素间距 16–24 px，组与组之间 40–56 px。
- **内容要铺开**：正文块和图要占满版心宽度（10–12 列），**不要让右边空着**。左右分栏时两栏都要有实在的内容。

## 一张内容页的组成

```
标题（结论句，锦书宋 72 px）
副标题（一句口径或补充，40 px，次级色）
│ 小主题 ①（左侧陶土竖条 + 48 px）
   一段 2–4 行的解释性正文（40 px，首行缩进两字）
   – 引导词：解释句（引导词用深陶土色高亮，不加粗）
   – 引导词：解释句
│ 小主题 ②
   ……  或：一张图表 / 截图 / 公式 / 表格，配 1–2 行说明
```

- **小主题块**：每页 1–3 个。每块是“小标题 + 一段话”或“小标题 + 3–5 条引导式要点”。
- **引导式要点**：`引导词：完整的解释句`。引导词 2–8 字，是这条要点的结论；冒号后用一句完整的话说清怎么回事。不写只有名词的要点。
- **正文段落**：用完整句子写清楚“是什么、为什么、怎么做”，首行缩进两个字。一段 2–4 行。
- **公式、表格、代码**可以直接出现在正文里，居中，前后各留半行。

## 信息量

- 一张内容页的正文（不算标题）一般在 **120–260 个汉字**，或者一张图表/截图加 60–120 字的解读。少于 80 字的内容页，先检查是不是只剩了关键词、该合并到相邻页。
- 超过约 300 字、或者需要第四个小主题时，拆成两页，不缩小字号。
- 一页只回答一个问题，所有块都服务于标题那句结论。
- 封面、章节页、大数字页、结尾页是例外，可以只有很少的字。

## 版式库

全篇从下面选 5–7 种，普通内容页结构保持稳定。

| 版式 | 结构 | 适合 |
|---|---|---|
| `cover` 封面 | 左 7 列：题签、作品名（96–110 px）、一句话说明、署名；右 5 列：主插画 | 第一页 |
| `section` 章节页 | 大号章节序号 + 章节名 + 一行本章要回答的问题 | 3 个以上章节时 |
| `text` 纯文字 | 1–3 个小主题块，每块一段话或引导式要点，可含公式 | 概念、论证、方法说明 |
| `split` 图文 | 左 6 列：小主题 + 正文；右 6 列：截图 / 插画 / 图表（或镜像） | 大多数内容页 |
| `columns` 三栏 | 2–3 栏，每栏图标 + 小标题 + 一段 3–6 行的正文，栏间细虚线 | 并列要素、对比 |
| `table` 表格 | 表格占满版心（≤ 7 行 × 6 列，单元格 ≥ 32 px），下方 1–2 行结论 | 指标、对照 |
| `chart` 图表 | 图表占 7–8 列并直接标注，右侧 4–5 列写“怎么读这张图”和结论 | 数据 |
| `flow` 流程 | 4–6 个节点，每个节点下有 2–3 行说明（输入什么、做什么、输出什么） | 系统、流程 |
| `figure` 大数字 | 2–3 个大数字，每个配单位和 2–3 行口径说明 | 结果、规模 |
| `closing` 结尾 | 愿景句或总结要点 + 署名 | 最后一页 |

## 不要这样做

- 整页只有标题和三五个关键词，右边一大片空白。
- 反过来，小字号长段落把页面排成论文；每段超过 4 行、或一页超过 300 字。
- 一页塞多个不相关话题。
- 版式和边距每页都变。
- 内容贴到页边。
