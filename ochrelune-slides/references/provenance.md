# 来源

整理日期：2026-11-18。整理人：Fennelia（中台），按 Milvoid 的要求编写。

## 设计理念

主要来源是 Milvoid 在交大水源社区发表的《一份详细的 Pre 用 PPT 制作指南》（https://shuiyuan.sjtu.edu.cn/t/topic/439568 ，经验分享 · 精品）。本 skill 的核心原则、布局、字体字号、用色（60-30-10、投影仪色彩陷阱）、强调（高亮代替加粗）、图像（圆角阴影、直接标注）、图标、动画（点击触发、平滑移动）和检查清单都来自这篇文章，换算到 1920×1080 画布（1 pt ≈ 2 px）并与 ochrelune 的视觉语言对齐。文章的立场是：大多数人需要的不是“PPT 秘诀”，而是 UI 设计的基本原则。

Milvoid 的 Keynote / PPT 模板 Midn-Plain（https://github.com/Milvoid/Midn-Plain/ ，介绍帖 https://shuiyuan.sjtu.edu.cn/t/topic/370430）提供了页面层级和信息量的直接参照。

## 视觉与制作

- 色板、字体方案：ochrelune-design（§4–§5，2026-11-18 字体方案）。
- 线描插画、描边生长、笔触层、叙事结构：ochrelune-video，来自 2026-11 交我创三支介绍视频的制作。
- HTML 方案的取舍：2026-11-18 与 Milvoid 讨论后确定。视频的设计、插画和叙事可以直接迁移；PowerPoint 做不出按帧绘制的动效，可编辑 PPTX 的字体也难以保证，所以 slides 采用 HTML 放映加 PDF 分发。需要可编辑 PPTX 的场合不用本 skill。

## 和视频的主要差异

Slides 由讲者控制节奏，观众会停下来读，所以一页是一个完整的论证单元，信息量远高于视频的一镜一句（第一版按视频的密度写，被 Milvoid 指出“信息密度太低”后按她的 Midn-Plain 模板重写：标题、副标题、带竖条的小主题、成段正文、带高亮引导词的要点，内容铺满版心）；动画只用于分步、引导和过程，并由点击触发；笔触只放在封面、章节和结尾。

## 第一个实例

样例页面使用交我创 01“超算集群低效作业识别系统”的内容；同一比赛的三份 pitch book（2026-11-18，v2 风格）是本方法的第一次实际应用。
