# Apple Event 风格总结页

Milvoid 的课程 Pre 会在最后放一张 Apple 发布会式的总结页（便当格拼版）。两个实例：2026-11-09 点融案例（`点融的下一笔投资-苹方版.png`），2026-11-19 沃尔玛期末 Pre（A 版“装车现场”）。

## 规则

总结页放在整份 deck 的最后。讨论问题在前一页抛出，约 30 秒的总结口播回顾主线，最后用一句话结束汇报并欢迎提问。

### 先选结论，再画卡片

- 从正文中挑出最值得带走的结论，全页通常安排 9–12 张卡，中央标题块计入总数。优先保留能认出案例、说明规模或解释决策分界的数字和图。每个入选要点出现一次。细节留在原页和讲稿里。
- 一张内容卡只有一个主角，选一个大数字或一幅插图。主角下方放一个单行短标签，通常不超过 8 个汉字。确有必要时在上方加一个不超过 4 字的引导词，指出约数、时点或统计口径。最多三层；删去解释句和成段灰字。
- 课堂算例只取结果，在同卡用小字标明“课堂算例”。必要的单位、比较符号和统计口径应随数字保留。若短标签仍说不清楚，换一个更适合独立阅读的结论。

### 拼版与字级

- 以真实发布会总结图为构图参考。画布为 3840 × 2160，中央圆角标题块与画面几何中心重合，使用低饱和暖色渐变，放官方标志和中文标题。
- 周围卡片用宽窄、长短的变化错落围合。只用圆角矩形，卡间距处处等宽，铺满画面，避免机械对称、整齐行列、重叠或空卡。卡片内部把主角、引导词和标签作为一组居中，统一内边距和层间距，为主角四周留出呼吸空间。
- 大数字用 **SF Pro Display Semibold**，字距略收紧。按渲染后的字面测量，数字字高为单行中文标签的约 2.5–3.5 倍，不要更大。普通数字取区间中低段，最重要的一两张卡可以接近上限。数字连同单位的总宽一般控制在卡片宽度的 65% 以内，四周留足空白。中文单位紧跟数字，字号小一档。引导词和标签用**苹方 Medium**，定稿后将文字转成轮廓。
- 缩小整页，先看见中央标题与各卡的数字或图，走近才读到标签。某张卡太挤时，先删字或换位置，保住字级差和内边距。

### 色彩和插画

- 借用 Apple 发布会的卡片拼版和字号层次。卡内沿用本套 deck 的 [ochrelune 插画语言](../../ochrelune-video/references/illustration.md)，从正文已有物件的轮廓、线宽和笔触开始，按场景现画。用线描表现环境和动作，避免套用苹果产品图形、SF Symbols 或通用图标库。
- 纸面色和燕麦色铺底。大数字用 ochrelune 暖色柔和渐变填充，从低饱和陶土色过渡到暖沙色或深燕麦色，整页统一渐变方向。强调数字用同一色系更深、更饱和的一档。以纸面为背景检查渐变最浅处的可读性。中文单位、引导词、标签和主要线条保持墨色。官方标志可选单色版本，保留原标志的轮廓和比例。素材原件、来源和绘制依据存入项目。
- [历史原始 prompt](../assets/summary/apple-summary-prompt.md) 留作拼版参照。画布、几何中心、间隙和裁切沿用原规范，卡片选点、字重、用色及插画按本页规则执行。

## 做法

1. 对照正文选定卡片主角、短标签和必需的口径标注，核准数字后排版。
2. 参考实现：[assets/summary/type-edition.mjs](../assets/summary/type-edition.mjs)（SVG 拼版、sharp 渲染为 4K PNG；路径是当时工程里的绝对路径，复用时改成本次工程）和 [assets/summary/text-outlines.swift](../assets/summary/text-outlines.swift)（用 CoreText 把苹方和 SF 文字转成路径，`swiftc text-outlines.swift -o text-outlines` 编译）。
3. **先出三版不同构图**和一张缩略对照图。三版选点与数字口径保持一致，通过主图、卡片跨度和阅读顺序拉开差别。选定后再放进 deck。
4. 构图选定后，保存该版 SVG 母稿。HTML 直接内联整幅 SVG，铺满末页，省去页眉和页脚。PDF 从同一份 SVG 导出静态终态。4K PNG 和缩略对照图用于审阅选图。

### 选定构图后的入场动画

- 把每张卡片的底、字形轮廓、标志或插画包在同一个独立的 `<g>` 中。用外层分组固定拼版坐标，对内层分组做动画，以便每张卡片在原位出现。
- 翻到总结页时，中央标题块先出现。其余卡片按各自中心到标题块中心的距离，由近到远依次淡入。每张用 400–500 ms、`ease-out`，配合轻微上移或从 96% 放大到 100%，缩放原点取卡片自身中心。相邻卡片间隔 60–80 ms，含标题块在内整段约 1.5 秒。用原生 CSS 或 Web Animations API 实现。
- 以页面进入放映状态为触发点，每次进入自动播放一次，页内点击数为 0。离页时清理播放状态，再次进入时从标题块重播。系统启用 `prefers-reduced-motion: reduce` 时，第一帧就完整显示所有卡片。
- 总览和打印使用静态终态。打印时让每张卡片完全可见、就位，并保留 SVG 字形与线条的矢量清晰度。
- 验收时把单文件 HTML 复制到空目录，双击打开。检查首次翻入、离开后返回、入场中途离开再返回，以及开启“减少动态效果”后的显示。在 3840 × 2160 下查看小字和细线，并将 PDF 末页与同一份 SVG 的终态比较。
