# Apple Event 风格总结页

Milvoid 的课程 Pre 会在最后放一张 Apple 发布会式的总结页（便当格拼版）。两个实例：2026-11-09 点融案例（`点融的下一笔投资-苹方版.png`），2026-11-19 沃尔玛期末 Pre（A 版“装车现场”）。

## 规则

- **总结页必须是整份 deck 的最后一页。** 讨论问题、提问邀请放在它前面；总结页口播约 30 秒，用一句“以上就是我们的汇报，欢迎老师和同学们交流提问”收尾，不再抛新问题。
- 她的完整 prompt 原文见 [assets/summary/apple-summary-prompt.md](../assets/summary/apple-summary-prompt.md)，逐条遵守。要点：
  - 3840×2160；正中央是主标题块，几何中心对齐画面中心，低饱和渐变背景，**放 Logo 加标题**（只放一行字会被认为“像是来糊弄的”）；
  - 其余模块错落环绕标题块，间隙全部一致，填满画面；不能有无意义留白、不能机械对称、不能像表格一样整齐；只用圆角矩形，不旋转、不重叠、没有空白卡片；
  - 一个要点一个模块，deck 里的要点全部出现，不重复、不遗漏、不自行补充；文案全部中文、短、克制；
  - 卡片大多是浅灰底；只用一种主色（从案例主体的品牌色出发，降低饱和度），只有一个大数字用主色和更重的字重；
  - 字体用苹方（中文）和 San Francisco（大数字），数字笔画轻、中文单位略小；文字转成轮廓再渲染，避免字体缺失；
  - 可以放真实素材：案例里的产品截图、关联图、官方媒体图库的实拍照片（照片上压暗渐变再放白字）；其余用简洁的线性小图标。素材来源记在 `summary/assets/素材来源.md`。
  - 课堂假设得出的数字在卡片里用小字标“课堂算例”。
- 她要的是 Apple 那种自然的高级感：被批评过“太 AI、一点也不 professional”“邯郸学步”。先找真实的 Apple Keynote 总结页看清卡片比例、留白和字重，再动手。

## 做法

1. 从 deck 各页结论里提炼 10–14 个要点（数字类、机制类、建议类、开放问题），和标题块一起排版。
2. 参考实现：[assets/summary/type-edition.mjs](../assets/summary/type-edition.mjs)（SVG 拼版、sharp 渲染为 4K PNG；路径是当时工程里的绝对路径，复用时改成本次工程）和 [assets/summary/text-outlines.swift](../assets/summary/text-outlines.swift)（用 CoreText 把苹方和 SF 文字转成路径，`swiftc text-outlines.swift -o text-outlines` 编译）。
3. **先出三版不同构图**交她选，选定后再放进 deck。
4. 放进 deck：HTML 里整页显示原图（不加页眉页脚），进页时整体淡入一次，不拆卡片做动画；PDF 嵌入 4K 原图，核对清晰度。
