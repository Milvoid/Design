# 动画与切换

动画只做三件事：**分步呈现**（控制观众读到哪里）、**引导视线**（信号原则）、**表现过程**（流程、状态变化）。说不出一个动画帮助什么被看见，就删掉它。所有动画都由讲者点击或按键触发，不自动播放。

## 分步呈现

- 在元素上标 `data-step="1"`、`data-step="2"`……，每按一次 → / 空格 / 翻页笔，显示下一组。已显示的元素保持不动。
- 出场统一：淡入并上移 16 px，0.5 秒，`cubic-bezier(0.2, 0.8, 0.2, 1)`。全篇同类元素只用这一种出场。
- 一次只出现一组；同屏同时在动的元素不超过一组。
- 要点列表、流程图节点、截图标注最适合分步；标题和页脚永远不做动画。
- 分步顺序跟讲稿的讲述顺序一致，每页讲者备注里写“点击 N 次”和每一步对应讲哪句。
- 常见图的分步：流程图和资金流向图逐个出现节点，箭头用描边画出；时间轴从左到右依次出现时点；柱状图和瀑布图的柱子从基线长出，数值随后淡入；盈亏分界图先后画出两条线，最后高亮交点；分解条、分支图逐段出现。
- 整页图片（如总结页）进页时整体淡入一次，不拆开做动画。

## 插画描边生长

- 来自 ochrelune-video：SVG 路径设 `pathLength="1"`、`stroke-dasharray: 1 2`，从 `stroke-dashoffset: 1` 过渡到 0；色块在描边过半后淡入；陶土那一笔最后出现。
- 在 slides 里时长压到 0.8–1.2 秒，并且只在这页第一次出现插画时播放一次。
- 适合封面、流程图（节点逐个画出）、关键隐喻图；普通配图直接显示。

## 页间切换

- 默认：0.35 秒淡入淡出，几乎感觉不到。
- **同一元素跨页平滑移动**（相当于 Keynote 的“神奇移动”、PowerPoint 的“平滑”）：两页上表示同一事物的元素设相同的 `data-morph="名字"`，切页时用 View Transitions API 让它从旧位置、旧大小平滑移动到新位置。例：流程图里的“检查用量”节点缩成下一页角落的流程条当前项；上一页的大数字移到下一页图表旁。这是保持“物体恒常性”、降低观众重新建构画面负担的主要手段。
- 浏览器不支持 View Transitions 时自动退回淡入淡出。

## 笔触层

- 只用在封面（角落一抹淡晕染）、章节页（一笔横扫的过渡底纹）、结尾页（片尾底景式的小画）。普通内容页不放。
- 放映时可以动态画出，也可以用预渲染的透明 PNG；导出 PDF 时用画完的最终状态。实现见 ochrelune-video 的 brush.md。

## 不要这样做

- 飞入、弹跳、回旋、缩放弹出、翻页、百叶窗等效果。
- 给每个元素都加动画；同类内容这页淡入、那页飞入。
- 自动计时播放、过慢的动画让讲者等画面。
- 动画结束后的状态和导出的 PDF 不一致（PDF 必须是每页全部步骤显示后的最终状态）。
